# 蕾米莉亚桌宠 · 使用说明

一个跑在桌面上的 Q 版蕾米莉亚：透明置顶、不抢焦点、可拖拽。她是飞行生物，平时**扇着翅膀低空悬浮着移动**，会撒娇、偷看你在干什么，还能和你聊天。

## 启动

```bash
npm install     # 首次
npm start
```

退出：右键任务栏/菜单栏那个**粉色小圆点** → 退出。

## 她会做什么

**动作节奏：每个动作停留 15 秒再换下一个**，左键点她可以立刻打断、切到下一个动作。

| 行为 | 说明 |
|---|---|
| 待机呼吸 | 每个动作之间会回到这个状态，随机冒气泡 |
| **飞行移动** | 扇着翅膀在桌面上低空滑行，一路掠到屏幕边再折返。**不再走路** —— 走路动画和生成脚本已删除，移动只用 `float` 那套展翅帧 |
| **常态悬浮** | 她的脚不踩桌面，而是浮在离底边约 12pt（身子高 120pt 的十分之一）的地方轻轻扇翅。睡下才缓缓落到桌面，醒来再浮起来 |
| **扇翅膀飞** | **靠扇翅膀升空**：翅膀以肩为轴上下扇动，越快扇幅度越大，配合整体升降；在离地 150pt 处盘旋，满 15 秒后落回地面 |
| **飞到屏幕顶上盘旋** | 沿着顶边一路扇上去，贴着屏幕顶端左右巡回，然后收翅滑降（原来那个「往上爬」的动作已经删掉，改成飞行） |
| **比猫耳朵 / 挥爪子 / 打滚 / 噘嘴 / 撒娇互动** | 轮流出现，播完会保持那个姿势，靠呼吸和眨眼继续「活着」 |
| **拖拽物理** | 按住拖动；松手带惯性抛出，撞到屏幕边缘会反弹，落地会压扁 |
| **落地抱头蹲防** | 落地瞬间双手抱头缩成一团，微微发抖；轻落地蹲 2.2 秒、从高处摔下来（硬着陆）蹲 3.4 秒，然后弹起来站好 |
| 睡觉 | 双击切换；睡 60 秒自己醒 |
| **屏幕边缘偷看** | 你 45 秒没搭理她，她会**扇着翅膀溜到**最近的屏幕边缘，藏掉 30%、双手扒着边探头偷瞄 —— 屏幕上留 70%，整张脸和双手都看得见，不会"找不到了"。点她一下 → 立刻缩回来 + 「才，才没有想看你在干什么呢！」然后站在原地赌气几秒 |
| 对话 | 单击托盘圆点 / 右键她 →「和我说说话」 |

动作按「洗牌袋」轮换：一轮里每个动作都会出现，且不会连着两次同一个。

## 尺寸与窗口形态

默认高度 **120pt**（比第一版的 60pt 放大了一倍）。窗口是**角色本体的正方形**（120×120），气泡是**另一个独立透明窗口**，贴在角色左边或右边自动翻边。

为什么拆两个窗口：气泡要占角色旁边一大条，共用一个窗口就只能靠 `setIgnoreMouseEvents(true/false)` 把空条「穿透」掉，而**每改一次窗口扩展样式都会连带冲掉置顶位、并打断正在进行的按下→移动→抬起序列**——那正是之前「右键没反应、抓不起来」的直接原因。现在角色窗口永不穿透、永不改样式，输入链路上一个开关都没有。

窗口类型是**工具窗口**（WS_EX_TOOLWINDOW）：不进任务栏、不进 Alt+Tab。

托盘 →「尺寸」可以换成「小一点（84）/ 默认（120）/ 再大（162）」。

## 交互速查

- **拖动**：按住她随便拖，甩起来她会飞出去
- **单击**：立刻换下一个动作（不等 15 秒）
- **双击**：睡觉 / 唤醒
- **右键她**：自绘快捷菜单 —— 和我说说话 / 扇着翅膀飞一下 / 比个猫耳朵 / 睡觉·叫醒 / 先藏起来 / 退出
- **右键托盘**：
  - 和蕾米莉亚聊天
  - 让它表演一个 → 扇着翅膀飞一段 / 展翅飞起来 / 去屏幕边上偷看 / 飞到屏幕顶上盘旋 / 猫耳 / 挥爪 / 打滚
  - 窗口置顶 / 安静模式 / 低闪烁模式 / 开机自启
  - AI 设置（面板内填 Key + 一键测试连接）
  - **小闹钟** → 整点报时 / 起身喝水提醒 / 番茄钟 / 夜间静音时段
  - 尺寸（更小 / 默认 / 再大）

## 小闹钟（实用提醒）

全部走桌宠气泡，不弹系统通知、不抢焦点、不进通知中心。

| 功能 | 默认 |
|---|---|
| 整点报时 | 每个整点冒一句带时间的台词，语气按时段换（深夜会催你睡） |
| 起身喝水提醒 | 每 50 分钟一句 |
| 番茄钟 | 25 分钟专注 + 5 分钟休息；专注最后 5 分钟每分钟报倒计时 |
| 夜间静音 | 23:00–08:00 不冒任何泡（跨零点正确判定） |

关键实现细节：**只有一个 20 秒的节拍**，按绝对时间判定，所以电脑休眠/唤醒后不会「一开机连珠炮补发一晚上的提醒」；静音期间照样推进时间戳，8 点一到也不会吐出积压的。

逻辑有离线验收脚本：`node scripts/test_reminders.js`（用模拟时钟跑满 26 小时，16 条断言）。

## 聊天窗口

风格是**绯红哥特洋馆**：夜黑底 + 血色斜纹壁纸、顶部一排哥特尖拱、烫金扇贝蕾丝分隔线、角落蔷薇水印；
头像直接用了她的 idle 立绘，外面套一圈金边 + 绯红光晕，而不是一个抽象的渐变圆。

对话气泡分两种：**她的**是暗酒红信笺形（左上角收直角、左下伸出一个小尖，像被递到面前），**你的**是绯红渐变圆角。
输入框聚焦时边框会亮成绯红，发送键做成一枚封蜡印。

## AI 对话

默认跑**本地人格引擎**（离线可用，会接话、会记你的名字和喜好、会算术、有情绪），不会真的推理。

想让她真聊，在**聊天窗口里点右上角徽章**（或托盘 →「AI 设置」）打开设置面板：

1. 服务选「agnes（agnes-2.5-flash）」
2. 填 API Key
3. 点 **「测试连接」**——它会真发一次请求，把耗时、模型名、对方原话都显示出来；失败会把服务端的原话带出来（是 Key 错了、余额没了还是地址不对，一目了然）
4. 点「保存」，下一句就用新设置，不用重启

也支持任何 OpenAI 兼容接口（服务选「其它 OpenAI 兼容服务」，地址和模型自己填）。

**记忆**：她会从对话里抽取并记住「称呼 / 喜欢什么 / 不喜欢什么」，注入到后续对话的系统提示里。抽取规则是保守的——否定句优先判断，宁可少记也不记错（「我不喜欢下雨」不会被记成「喜欢下雨」）。

远端调用失败时会自动退回本地引擎，她不会哑掉。Key 在界面里始终脱敏显示（`****abcd`），回传时也不会把真 Key 覆盖掉。聊天记录存在应用数据目录的 `chat-history.json`。

## 性能与画面闪烁

桌面宠物是「透明 + 置顶 + 无边框」窗口，这类窗口每绘制一帧，Windows 的桌面合成器（DWM）就要重新合成一次它覆盖的区域。如果一直按 60fps 全速绘制，在部分显卡/缩放比例下会出现**桌宠所在的屏幕角落持续闪烁、鼠标指针经过时也闪**。

默认开启的**低闪烁模式**做了几件事：

| 场景 | 实际绘制频率 |
|---|---|
| 拖拽 / 掉落 / 飞行移动 / 漂浮 / 偷看 | 30fps |
| 一次性动作（挥手/撒娇/挥爪…） | 20fps |
| 待机呼吸 | 12fps |
| 睡觉 | 6fps |
| 待机静止 12 秒无人理会 | 冻结，约 0.25fps（每 3 秒补一帧防花屏） |

鼠标一移上去就立刻解冻恢复动画。另外：窗口位置更新合并为每 16ms 一次、鼠标穿透只在命中状态真的变化时才切换。

觉得动画不够顺滑，可以托盘 →「低闪烁模式（省电）」取消勾选，恢复全速 60fps。

## 关于「角色身上缺几块」

这个问题有两个独立原因，都修了：

1. **主因是素材**：抠图用的是「全局颜色键」——把接近纯白的像素一律挖成透明，于是白蕾丝、皮肤高光、白领口这些真正的角色内容也被挖掉，最严重的帧有 50% 的角色像素是透明的。已改为**只挖与画面边缘连通的背景色**（flood fill），全部 14 个状态重建，内洞归零。
2. **次因是合成**：透明置顶窗口里的硬件加速 canvas 会被 Chromium 提升成 DirectComposition 的 overlay 平面，overlay 无法与桌面正确做 alpha 混合，表现为块状透明缺口。修法是让 WebGL 只画在**离屏 canvas** 上，再拷贝到屏幕上的 2D canvas —— 显示层走常规合成路径。

门禁已经补上**内洞检测**：角色内部透明像素占比 > 2% 直接 FAIL。这个缺口之前能一路 PASS 到验收桌上，就是因为门禁只查尺寸和帧间差异，不查 alpha 连续性。

## 关于「窗口越走越大」

移动窗口时如果从 `getBounds()` 读回尺寸再写回 `setBounds`，这个透明 + toolbar + noactivate 的窗口会把 DWM 的边框一点点算进 bounds，**每移动一次涨一点**：漂浮 4 秒就从 170×40 涨到 200×82。

修法：移动时把**已知正确的尺寸显式钉住**，永远不从读数里取。G3 门禁新增 `sizeOk`，尺寸偏离基线就 FAIL。

## 关于「气泡 / 菜单明明在、屏幕上却看不见」

透明置顶窗口有个反复踩的坑：**改窗口扩展样式（`SetWindowLong GWL_EXSTYLE`）会把 `WS_EX_TOPMOST` 位一起冲掉**，但 Electron 内部的 alwaysOnTop 标记仍然是 `true` —— 所以直接再调 `setAlwaysOnTop(true)` 是**空操作**，必须 `false → 隔 40ms → true` 分两拍才真落到系统上。

三个连带结论，都在代码里落实了：

1. `setIgnoreMouseEvents(true)` 会加 `WS_EX_LAYERED` 并冲掉 TOPMOST → 气泡窗创建时设一次穿透，之后**永不改样式**，置顶靠 `healBubbleTopmost()` 补。
2. 对**还没显示**的窗口调 `setAlwaysOnTop` 会落空（实测 `ok=false`）→ 一律在 `showInactive()` 之后补。
3. 透明窗**第一次合成**时 Chromium 会重刷自己的样式、把 TOPMOST 抹掉好几次（实测要重试 3~4 次）→ 启动时先 `warmUpBubble()` 把气泡窗预热好，否则开机头一两句气泡是看不见的。

`win.isAlwaysOnTop()` 在 Windows 上读的就是真实的 `WS_EX_TOPMOST` 位，可以当探针用。`scripts/topwatch.py` 能实时采样这个位有没有在抖。

素材透明度体检：`python scripts/fix_alpha.py --check`（也会在 `gate_check.py` 里自动跑）。
它查三件事：帧内部有没有 alpha=0 的洞、主体内部有没有半透明块、贴近角色的透明区 RGB 有没有被清零 ——
最后一条是帽子在浅色桌面上「透了一块」的真凶（mipmap 平均时把边缘颜色往黑里拉）。

## 调手感

改 `src/renderer/config.json`：

- `behaviors.actionHoldMs` **每个动作保持多久**（默认 15000 = 15 秒）
- `behaviors.physics.gravity` 重力、`hardLandingSpeed` 摔多重才倒地
- `behaviors.float.hoverHeight` 漂浮高度、`driftSpeed` 漂移速度
- `behaviors.float.topMarginRatio` 飞到屏幕顶上时离顶边的距离（按角色高度的比例，默认 0.08）
- `animations.fly.moveSpeed` 飞行移动速度（默认 130）、`fps` 振翅帧频
- `behaviors.fly.hoverHeight` 常态悬浮离地高度（默认 12pt，设 0 就变回贴地站着）
- `behaviors.peek.hideRatio` 偷看时藏掉多少（默认 0.30 = 屏幕外 30%，屏幕内留 70%）
- `behaviors.idleBubbleSec` 待机冒泡间隔、`sleepAutoWakeSec` 睡多久自己醒
- `behaviors.landing.crouchHoldMs` 轻落地蹲多久（默认 2200）、`hardHoldMs` 高处摔下来蹲多久（默认 3400）、`riseMs` 起身弹性时长（默认 320）

改完重启生效。动作出场顺序在 `src/renderer/renderer.js` 的 `ACTION_POOL` 里。

## 开机自启

托盘 →「开机自启」勾上即可。Windows 上写的是 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`。

开发态有个坑已经处理：只写 `openAtLogin` 会注册成「开机拉起一个空的 Electron」。现在的实现显式带上了 `path`（exe 路径）和 `args`（开发态是工程目录，打包后为空），实测开→关→查三次注册表都正确，关掉后条目会被干净移除。

## 页面避让（新）

打开**任何别的程序 / 页面**（浏览器、文件夹、游戏、文档……只要前台窗口不是她自己，
也不是她的对话·菜单·气泡窗），她会**滑到最近的屏幕边缘、留一大半身子在屏幕里**悄悄看着你，
绝不会像以前那样"全屏一开人就没了"。那个窗口关掉 / 你切回桌面或她自己、或你**点她一下**，
她就立刻滑回来。

- 触发很宽：任何"非本程序的别的窗口"都会让她躲；桌面 / 任务栏 / 她自己的窗口不触发。
- **始终可见**：她只藏掉约 30%（`behaviors.peek.hideRatio`），脸和手都在屏幕里，找得到人。
- 回来条件：页面关了 / 回到桌面 → 自动回来；或者点她露出的那部分 → 立刻"跳出来"。
- 实现：主进程常驻一个 PowerShell 小监视器（Windows 自带，无需 Python/原生编译），
  轮询前台窗口所属进程是不是我们自己的 exe，只把布尔事件发给渲染器。
- 日志里能看到：`[winwatch] started` / `[winwatch] hide=true|false`、
  `[pagehide] start side=..` / `[pagehide] end`、点她时 `[input] pagehide dismissed by click`。

## 已知限制

- **新增动作姿势需要新素材**。「偷看」是复用 `grip`（双手扒边）那套帧 + 网格式探头倾斜做出来的；「落地抱头蹲防」是从你给的那张立绘**形变派生**出来的 6 帧（以脚底为支点做压扁/拉伸/上身摆动，帧间差异 28%~50%），不是另外画的 6 个姿势。凭现有素材画不出「打滚」「伸懒腰」这类全新的身体姿态。
- 眼睛的高光色偏红，是原素材本身的颜色，还没校过。
- macOS 侧代码走同一套 `platform.js` 适配层，但**没有在真机上跑过**（打包环境是 Windows）。
